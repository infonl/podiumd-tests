# ZAC test scenarios: gaps in podiumd-tests

Analysed 2026-11-08: the manual test scenarios of ZAC's development team (per sprint and the regression test before PodiumD 4.10),
clustered by behaviour and compared with the tests in `tests/`. Scenarios covered at that analysis, obsolete and UI-only
ones are not listed; the summary's obsolete and out-of-scope columns count them.

The batches that close these gaps: [`zac-port-plan.md`](zac-port-plan.md).

## Scope

- PodiumD 4.10 runs ZAC 5.9.1 (`zac.image.tag` in helm-charts `charts/podiumd/values.yaml`). Only behaviour in ZAC 5.9.1 counts: everything up to 5.9.0 plus the fixes released in 5.9.1.
- PodiumD 4.9 runs ZAC 5.4.x and PodiumD 4.8 ZAC 5.0.x: a test for behaviour after that needs a ZAC version gate (Min ZAC column).
- covered: a test asserts the expected result; partial: the flow runs, the expected result is not asserted; gap: no test.
